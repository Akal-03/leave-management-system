# Leave Management System

## About
A web-based Leave Management System that allows students to apply for leave and staff members to manage leave requests.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas

## Features
- Student Registration and Login
- Staff Login
- Apply for Leave
- View Leave Requests
- Approve or Reject Leave Requests
- Leave Status Tracking
